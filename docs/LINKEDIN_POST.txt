I built a little cybersecurity game because access control is easier to understand when something is chasing you.

Meet Ghost Protocol.

Play Ghost Protocol: https://ghost-protocol-b74p.onrender.com/

It’s a browser maze game where you collect access keys, recover a package, and avoid patrolling sentries. The twist? The sentries get a copy of your Vault access. Getting out means knowing which permission to revoke—and which one you still need.

I built this with Codex. I directed the gameplay, visuals, and learning experience, while Codex handled implementation and testing.

A lot of the process was playing it, spotting something confusing, and working through another revision. Enemies needed to move independently. The maze needed proper dead ends. A key-selection menu kept interrupting the chase. And the lockdown switch needed to be somewhere people could actually find it.

Apparently “just lock the door” needs a very clear button.

The project connects with the work I enjoy: troubleshooting, documenting decisions, making technical concepts understandable, and checking that a fix solves the problem without breaking someone else’s workflow.

That’s also the security lesson. Removing compromised access matters. So does making sure legitimate work can continue.

The video gives you a look at the game. The GitHub write-up covers how we built it, including the hosting problems we had to work through.

Explore the project: https://github.com/JarthurLabs/ghost-protocol

It runs on free hosting, so the first visit may take a little time to wake up.
